Support

Help with the Katevazo app and the Send to Katevazo browser extension.

Report a problem or ask a question

Open an issue on GitHub. Please say which system and app version you use, and what you expected to happen.

Open an issue

The extension says "App not found"

  • Install the latest Katevazo app from the Releases page.
  • Open the app once. It registers itself with your browsers each time it starts.
  • Reopen the extension's popup.
